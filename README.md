
## kribil-limp Cue Crew game


"крибил" - на бильярдном столе один игровой шар1. команда должна провести его через все контрольные точки. Быстрее - лучше. Толкать кием можно только битки - но не игровой шар1.

4 контрольные точки, 4 игрока в команде.

2 modes of game/calculation:
- битки можно ставить где угодно после фиксации маршрута контрольных точек. Рассчёт включает установку в нужные позиции.
- битки ставятся вместе с маршрутными точками перед игрой.

select balls and control points with pointer
- режим перемещение drag.
- режим установки силы, направления и времени. А для контрольных точек - размер области.

важно - отображается вся траектория шар1 и битков с учётом всех ударов (ограничение полной длины выбрать разумное чтобы не зависло). цвет кодирует время. в том числе в планировщике - интерактивно видно. таким образом удобно графически определить влияние настройки битков.

Опции настройки масс (по умолчанию 1.0) и трения (от нуля), размер шаров.

Слайдер анимации времени - можно двигать чтобы переместилось в точку t.

на Шкала времени интерактивно отображаются времена соударений шаров и диапазон времени прохода через контрольную точку.

очевидно, что задача сводится к расчету траекторий и импульсов.

сделай unit тесты для проверки что биток попадает по шар1, шар проходит через контрольную точку, общее время до того как шар1 достигнет финиша

Игрок может играть realtime за одного из игроков команды или использовать режим - планировщик - интерактивный расчёт траектории, удобное задание направлений, времени и силы удара каждого из игроков команды.

## Реализация (plain JS)

Итоговая игра лежит в корне репозитория: `index.html` + `js/` + `css/` +
`tests/`, без сборки и зависимостей. Откройте `index.html` двойным кликом
(работает по `file://`) или поднимите статику: `python3 -m http.server`.

- `js/` — физика, симуляция, траектории (`Traj` на типизированных массивах),
  leg-based решатель с ансамблем сидов, 4 стратегии ботов, живой движок 240 Гц,
  рендер time-color траекторий и всё приложение (`js/app.js`);
- вкладки справа: **Расстановка** (пресеты, физика, массы/трение/размер, копия/вставка JSON),
  **Команда** (удары `t/угол/сила` относительными лог-слайдерами; вживую — выбор своей позиции и боты),
  **Решатель** (автопоиск: градиент, координатный спуск, перестройка ног, ансамбль, чек-лист и журнал);
- шапка: план/вживую, замок/свободная расстановка, тащить/целиться, рекорд маршрута;
- таймлайн: градиент времени, чёрточки ударов и КП, окна прохода, перемотка, скорости;
- живой режим: мышью прицельтесь, зажмите для набора силы, отпустите — удар;
  клавиши 1–4 смена позиции, пробел старт/пауза, точка — покадрово;
- тесты: `npm test` (9 проверок, включая обязательные: контакт, проход точки, время финиша);
  дымовой DOM-тест опционален: `npm i -D jsdom && npm run smoke`.

Подробная спецификация-артефакт: `plan-kribil-plainjs.md`; сравнение попыток
A/B/GLM53f — `attempts-comparison.md`; заметки для агентов —
`findings-pitfalls-skills.md`.
